## 🔍 Key Features

Smart Feeds provides:

- **📰 RSS Feed Aggregation**: Centralized content from multiple sources
- **📁 Folder Organization**: Theme-based source categorization
- **📋 Personal Boards**: Individual content curation
- **👥 Team Collaboration**: Shared content boards with permissions
- **🔍 Content Discovery**: Trending articles and category exploration
- **🔔 Real-time Notifications**: Stay updated with latest content
- **🌙 Dark/Light Themes**: Customizable user experience

## 🏛️ Architecture Highlights

- **Frontend**: React 19 + TypeScript + Styled Components
- **Authentication**: Keycloak SSO integration
- **State Management**: React Context API
- **API Communication**: Axios with automatic token refresh
- **UI Library**: Material-UI components
- **Deployment**: Docker containerization support
